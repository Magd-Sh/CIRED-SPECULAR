# SPECULAR

Data, code and outputs behind the master's thesis *Mapping employment change in
the European automotive industry*, written at CIRED, 2026.

**Read `README.md` in this folder.** It lists what is in each of the four
numbered folders, says which command produces what, and explains the two
definitions that are easy to get wrong.

The short version:

```bash
mamba env create -f environment.yml && mamba activate specular
python run_all.py          # rebuilds every figure into 04_outputs/
```
